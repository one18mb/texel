# 字画 · texel

> 极简像素草稿本：**笔迹层（下）+ 文字层（上）**，鼠标只画、键盘只写，历史摊在底栏。
> 单文件、静态链接、无运行时依赖的原生 Windows 程序（~4.5 MB，含完整点阵字体）。

---

## 它是什么 / 不是什么

**是**：一张固定大小的像素画布，同时是「打字机」和「涂鸦板」。文字在上、笔迹在下（文字压在笔迹上）；鼠标不碰文字，键盘不碰笔迹。

**不是**：不是行编辑器，不是绘图软件，不是笔记软件。没有图层管理、画布不滚动缩放、没有工程文件、没有富文本排版。

---

## 设计原则（核心）

1. **零模式**：鼠标永远是"画"，键盘永远是"写"。没有工具切换、没有"当前是选择还是画笔"的模糊态。
2. **光标 = 一个字的选区**：光标本身就是最小的选区；**长按/拖动 = 把选区放大**。「选中」和「输入」不是两种状态，而是同一个东西的两种大小。
3. **一切皆空间**：**空行、空格、空列都是占位**，是内容而非噪音。选区是矩形，粘贴就落一个同形状的矩形，**不裁剪**。
4. **无隐藏状态**：画布固定尺寸、不滚动不缩放（窗口可自由缩放）、文字恒在上笔迹恒在下、选区绝不切半个字。没有"怎么突然不对了"的隐藏规则。
5. **像素诚实**：Unifont 点阵逐像素 blit，**无抗锯齿**，16×16 网格对齐，所见即所得。
6. **时间可见**：撤销栈摊成底栏那行「写画写画」，深色=已应用、灰色=已回撤，点一下就切换。

一句话：**用限制换确定性**。

## 操作速查

### 鼠标
| 操作 | 作用 |
|---|---|
| 左键单击 | 把文字光标定位到点击处 |
| 左键长按（约 0.4s）/ 拖动 | 矩形选中，选中区反色 |
| 右键拖动 | 画笔 |
| 右键拖动 + Shift | 八向直线（水平/垂直/45°） |
| 滚轮 | 调整画笔粗细（1–64） |
| 左键点底栏某一格 | 切换历史位置（点灰色=重做，点深色=回撤到那） |

### 键盘
| 按键 | 作用 |
|---|---|
| 打字（含中文/emoji） | 覆盖当前格，光标右移 |
| 方向键 | 光标二维移动（不出画布） |
| Home / End | 行首 / 行尾 |
| Enter | 光标到下一行行首（**不产生换行字符**） |
| Backspace | 删左边一个字 |
| Ctrl+A | 全选 |
| Ctrl+C | 复制当前选区（无选区=光标所在那个字） |
| Ctrl+X | 剪切（复制 + 删除，一次操作） |
| Ctrl+V | 粘贴（算一次「写」） |
| Ctrl+Z / Ctrl+Y | 回撤 / 重做 |
| Ctrl+S | 保存（PNG 或 `.texel.zip`，默认 `.texel.zip`） |
| PageUp / PageDown | 无绑定 |

> 快捷键仅在画布有焦点时生效；焦点在顶栏输入框时按键归输入框，Esc 可退回画布。

### 打开 / 拖放
- **新建**：直接打开 `texel.exe`（无参数）进入设置模式，填宽/高/背景/前景后点「新建」。
- **打开**：把 `.texel.zip` 拖到 `texel.exe` 图标上 = 以该文件尺寸新开进程打开；设置模式里也有「打开」按钮。
- **拖入 / 粘贴**：往画布里拖入文件、或从外部程序拖入文本选区/图片，`.texel.zip` 打开、图片 1:1 贴图、文本按当前色写入（粘贴算一次「写」）。

### 顶栏（高 24px）
```
[帮助] [粗细] [颜色] | [当前][前景][背景][透明] | [经典16色] | [历史色块…]
```
- **帮助**：点一下弹出完整帮助。
- **粗细**：画笔直径 1–64，回车生效；滚轮也会同步这个框。
- **颜色**：当前画笔色的 `#RRGGBB`；透明时留空。改颜色后**追加一个历史色块**，栏满则挤掉最旧的「非固定」色块（当前/前景/背景/透明与经典16色固定不动）。
- 点任意色块 = 选为当前画笔色。

### 底栏（高 17px，历史时间轴）
- 从左向右生长，一格代表一次操作：**写**=文字、**画**=笔迹。
- 深色=已应用，灰色=已回撤。
- 容量 = `画布宽 ÷ 16` 条；满了之后**一进一出**（最老的被挤出，同时被"固化"进画面，不可再撤销）。

## 选区 / 剪贴板模型

- **光标 = 单字选区**：没框选时，`Ctrl+C/X` 作用于光标盖住的那个字（全角整个字；空格也复制成空格）。
- **选区 = 放大的光标**：长按拖动拉出矩形；`Ctrl+C/X/V` 一律作用于"当前选区"。
- 选区边界**外扩到字形边界**，绝不切半个字。
- 光标落在选区内时**并入**选区显示（否则反色会二次抵消，缺个角）。
- 剪切 = 复制 + 删除，**一条历史记录**；粘贴 = **一条「写」**，可一次整体回撤。
- 选区含**文字与笔迹**（同一矩形区域）；复制/剪切/粘贴**连颜色与笔迹一起**搬（私有格式 `texel-cellblock` v2）。
- **粘贴为"图章"**（语义 b）：只贴有内容处（有字/不透明像素），透明与空格处**不动目标**原有内容。
- 从**外部**程序粘贴的纯文本只有文字，一律用"当前"色。
- **粘贴图片**：复制一个图片文件（PNG/BMP/JPG…，走文件 / 剪贴板位图 / `PNG` 等来源）后 `Ctrl+V`，会**以光标为左上角、1:1 像素**贴到笔迹层，**超出画布的部分忽略**（画到哪算哪）。

## 配置 `texel.ini`

与 `texel.exe` **同目录**，可手动编辑：

```ini
[cfg]
W=...            ; 画布宽（半角列，8px）
H=...            ; 画布高（行，16px）
Bg=FFFFFF        ; 背景色
Fg=000000        ; 前景色（初始画笔色/当前色）
X=...            ; 主窗口位置（自动记录）
Y=...
Pos=1            ; 是否已有记录位置
NoSavePrompt=1   ; 退出不提示保存，直接关闭
WheelGain=1024   ; 滚轮加速封顶(与画布无关；越大越快)
```

- 退出提示里的 **「否，不再提示」** = 写入 `NoSavePrompt=1`。
- 程序**只读取** `NoSavePrompt` / `WheelGain`，不会覆盖你手填的值。

## 文件格式：`.texel.zip`

原生保存格式（**不含历史**），就是一个普通 zip，内含四个文件：

| 文件 | 内容 |
|---|---|
| `text.txt` | UTF-8 文本，**每画布行一行**；行内是该行的字（左→右，不留空位填充） |
| `txt.color` | 每行对 `text.txt` 同行每个字给一个 `列:颜色` 记号（列=字形起始 8px 列；颜色=`RRGGBB` 或 `t`=透明） |
| `ink.png` | **只存墨迹层**（别处透明）；尺寸=画布像素尺寸，**打开时由它决定画布大小** |
| `bg.color` | 背景色：`trans`（透明）或 `RRGGBB` |

- 两层各一个文件（文字=`text.txt`+`txt.color`，笔迹=`ink.png`），**可重开继续编辑**。
- 背景色单独存 `bg.color`；`ink.png` 始终透明，导出 PNG 用真实背景色。

## 构建

依赖：`mingw-w64`（交叉编译）、`python3`。

```bash
# 1) 取字体点阵（主表 + 1–15 平面）
curl -L -o unifont.hex.gz       https://unifoundry.com/pub/unifont/unifont-18.0.01/font-builds/unifont-18.0.01.hex.gz
curl -L -o unifont_upper.hex.gz https://unifoundry.com/pub/unifont/unifont-18.0.01/font-builds/unifont_upper-18.0.01.hex.gz
gunzip -kf unifont.hex.gz unifont_upper.hex.gz

# 2) 生成嵌入用点阵
python3 tools/mkfont.py src/font.bin unifont.hex unifont_upper.hex

# 3) 交叉编译
./build.sh        # 产出 texel.exe（~4.5MB，单文件静态）
```

`build.sh` 关键点：`-municode -mwindows`、静态链接、`-Wl,--gc-sections -s` 瘦身、链接 `gdiplus/gdi32/imm32/comdlg32` 等系统库。

## 代码结构

```
texel/
├─ src/
│  ├─ texel.cpp       主程序（~2100 行）
│  ├─ texel.rc        资源：图标、清单、版本信息、保存对话框、点阵 RCDATA
│  ├─ resource.h         资源 ID
│  ├─ texel.manifest  应用清单（asInvoker / dpiAware）
│  ├─ texel.ico       图标
│  └─ font.bin           合并后的点阵（115053 字形，37B/字形）
├─ tools/mkfont.py       .hex → font.bin 预处理器
├─ build.sh              构建脚本
├─ unifont.hex           Unifont 主表（BMP 等）
└─ unifont_upper.hex     Unifont 1–15 平面（SMP）
```

`texel.cpp` 主要分区：字形查找 → 合成（`renderText`/`compose`）→ 格子操作 → 剪贴板 → 画笔 → 历史时间轴 → 顶栏/底栏/选区绘制 → 输入框/IME/导出/配置/对话框 → `WndProc` → `wWinMain`。

## 数据模型

**图层（下→上）**：背景色 → 笔迹层 → 文字层。（文字压在笔迹上；"透明"画笔擦除墨迹、露出背景。）

**文字**：`g_cells` + `g_cellColor`——每格一个 32 位码点（BMP + SMP 全覆盖）**加一个 ARGB 颜色**（打字时的"当前"色，透明=有字无色）。`0`=空，`0xFFFFFFFE`=全角字右半格（CONT）。半角占 1 列（8px），全角占 2 列（16px）。

**笔迹**：`g_ink`（ARGB 位图，仅 alpha=0/255）。

**历史时间轴**：`g_ops`（`Op` 序列）+ `g_pos`（已应用数）。
- 文字操作以**矩形块**存 `before`/`after` 两个矩阵（所以粘贴/剪切这种多格改动也是一条记录）；
- `rebuildState(p)` = 从**基准态**出发，重放 `g_ops[0..p)` 得到画面。

**基准态拆分（性能关键）**：
- `g_baseCells`（文字，仍是格子）+ `g_baseInk`（笔迹，**已栅格化位图**）；
- 一条操作被挤出历史时：文字写进 `g_baseCells`，笔迹**增量盖到 `g_baseInk`**；
- 于是回撤成本 = 一次画布拷贝 + 重画时间轴里剩下的少数几笔，**与历史长度无关**。
- 文字不栅格化，因为后续操作可能清除/覆盖基准态里的格子，位图抠不掉字；而格子拷贝便宜、排版开销只跟画布大小有关。

**字体**：`font.bin` 记录 = `码点(uint32 LE) + 宽度(1/2) + 16 行 × uint16`；`getGlyph` 二分查找。

## 刻意不做的事（Non-goals）

- 图层管理、缩放 / 滚动 / 平移、多文档
- 打开/保存工程文件（`.texel.zip` 只存两层 + 一个 PNG，不含历史，不是工程文件）
- 比例字体、排版（字距、字号混排）
- 把笔迹当"对象"去选取 / 移动 / 变换
- 选中后按 Backspace 删除选区（会和"单字光标"逻辑矛盾；**Ctrl+X 就是删选区**）

每加一个都会往"隐藏状态 / 模式"里塞东西，破坏上面那套闭合模型。

---

## 已知边界（都是取舍，不是缺陷）

- **无持久化**：关掉即清空（草稿定位），只有退出时的保存提示兜底。
- **画布固定尺寸**：打开按 ini 的 W/H（宽=半角列 8px，高=行 16px）；画布不滚动、不缩放（窗口可自由缩放、不超屏幕，画布居中）。
- **字体覆盖 = Unifont 覆盖**：Unifont 未收录的新字符会显示空白。
- **无代码签名**：部分杀软会误报，需自行加信任；`signtool` 可直接签名该 exe。
- **第三方输入法**：极少数 IME 组合时可能与方向键/回车抢，遇事再针对性处理。

---

## 理念一句话

> **画布上的一切都是空间** —— 空行、空格、空列都是占位；光标是最小的选区，选区是放大的光标；鼠标只画、键盘只写，历史摊在眼前。

这个工具用限制换来了确定性：**零模式、无隐藏状态**，所以看似简陋，交互却比功能堆砌的软件更顺。
